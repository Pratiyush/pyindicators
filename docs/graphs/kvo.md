# `kvo` — visualization ideas

> **Klinger Volume Oscillator, Klinger** · category **volume** · reads `high, low, close, volume` · outputs `kvo`, `kvo_signal`

**What it measures.** long-term money-flow oscillator — fast minus slow EMA of volume signed by HLC3 trend.

## Where to draw it

**A separate pane below the price chart**, aligned on the same time axis. Centre it on its zero/neutral line so positive vs negative is obvious at a glance.

## Scale & reference lines

Auto-scale to the data; add a **zero line** if it oscillates around zero.

## Rendering each output

- `kvo` → a line.
- `kvo_signal` → a thinner **signal line** over the main line; mark crossovers.

## Visual signals to highlight

- **Zero-line crosses** — colour the area above zero green, below red; mark each cross.
- **Histogram** — for *_hist columns, draw vertical bars from the zero line (rising/falling colour).
- **Signal-line cross** — where a *_signal line is present, mark fast-crossing-signal events.
- **Divergence** vs price for momentum-type readings.
